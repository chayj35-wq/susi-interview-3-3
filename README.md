# 홍익디자인고 3-3 수시 면접전형 준비 사이트

3학년 3반 학생들이 각자 번호·이름 페이지에 들어가 대학 리서치, 자기소개, 예상 질문을
직접 입력하고, 담임 선생님(차윤정)이 한 곳(구글 시트)에서 모아 볼 수 있게 만든
GitHub Pages 사이트입니다.

- 학생용: `students/<번호>/index.html` — 사이트에서 바로 작성 후 "제출하기"
- 관리자용: `admin/index.html` — 전체 응답을 구글 시트로 한눈에 확인 (⚠️ 아래 5번 주의사항 필독)

이 사이트 자체는 화면(UI)만 제공하고, 학생이 입력한 내용은 **구글 폼(Google Forms)을
거쳐 구글 시트에 자동으로 쌓이는 방식**입니다. 정적 사이트(GitHub Pages)는 스스로
데이터를 저장하지 못하기 때문에, 아래 순서대로 구글 폼을 한 번만 만들어 연결해주세요.
한 번 연결하면 학생 24명 모두 같은 설정을 사용합니다 (학생마다 따로 설정할 필요 없음).

---

## 0. 입장 비밀번호 설정하기 (권장, 한 번만)

우리 학생들만 들어올 수 있도록, 사이트 전체에 **비밀번호 입장 화면**을 걸어뒀습니다.
`assets/config.js` 를 열어 아래 두 값을 원하는 비밀번호로 바꿔주세요.

```js
sitePassword: "학생들에게_알려줄_비밀번호",
adminPassword: "선생님만_아는_관리자_비밀번호",
```

- `sitePassword` — 메인 목록·학생 개인 페이지에 쓰는 비밀번호. 학생들에게 문자·공지 등으로 알려주세요.
- `adminPassword` — `admin/` 페이지 전용 비밀번호로, `sitePassword`와 **반드시 다르게** 설정하고 학생에게는 알려주지 마세요.
- 한 번 맞는 비밀번호를 입력하면 그 브라우저에서는 계속 로그인 상태로 유지됩니다(다시 물어보지 않음).
- `robots.txt`와 각 페이지의 `noindex` 설정으로 구글 등 검색엔진 노출도 막아뒀습니다.

> ⚠️ **이건 진짜 서버 보안이 아니라 "가벼운 문단속"입니다.** 페이지 소스 보기(마우스 우클릭 →
> 페이지 소스 보기)를 할 줄 아는 사람은 `assets/config.js`에서 비밀번호를 그대로 볼 수
> 있어요. GitHub Pages 자체를 무료 계정에서 진짜 비공개로 만들 방법은 없습니다(조직용
> GitHub Enterprise에서만 지원). 검색 노출과 링크를 모르는 외부인의 우연한 접근을 막는
> 용도로 쓰시고, 정말 민감한 내용은 애초에 이 사이트에 올리지 않는 걸 권장합니다.

## 1. 구글 폼 만들기 (한 번만)

[forms.google.com](https://forms.google.com) 에서 새 설문지를 만들고, 아래 11개
문항을 **정확히 이 순서·이름**으로 추가하세요. (문항 이름은 자유롭게 바꿔도 되지만,
아래 "필드 유형"은 꼭 맞춰주세요.)

| 순서 | 문항 이름(예시) | 필드 유형 |
|---|---|---|
| 1 | 반 | 단답형 |
| 2 | 번호 | 단답형 |
| 3 | 이름 | 단답형 |
| 4 | 컨셉 키워드 | 단답형 |
| 5 | 자기소개 스크립트 | 장문형 |
| 6 | 지원동기(공통) | 장문형 |
| 7 | 진로계획 | 장문형 |
| 8 | 특성화고 선택 이유 | 장문형 |
| 9 | 관심 이슈·작가 | 장문형 |
| 10 | 지원 대학 조사 | 장문형 |
| 11 | 예상 질문·답변 | 장문형 |

모든 문항은 **필수(*) 해제**로 두세요 — 학생이 일부만 채우고 제출할 수도 있습니다.

## 2. 문항별 `entry.` 번호 확인하기

1. 폼 오른쪽 위 점 3개 메뉴(⋮) → **"미리 채워진 링크 받기"**
2. 각 문항에 아무 값이나 입력하고 (예: 1번 문항에 `테스트1`, 2번에 `테스트2`…) 링크 생성
3. 생성된 긴 주소를 복사해서 메모장에 붙여넣으면 아래처럼 보입니다.

```
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/viewform?usp=pp_url&entry.111111111=테스트1&entry.222222222=테스트2&...
```

`entry.111111111=테스트1` 이 "테스트1"을 넣었던 문항(반)의 ID입니다. 이런 식으로
11개 문항 모두 `entry.숫자` 값을 확인하세요.

또한 주소의 `/d/e/1FAIpQLSxxxxxxxx/` 부분이 폼 ID입니다. 이 ID를 아래 폼 제출 주소에
그대로 넣어야 합니다.

```
https://docs.google.com/forms/d/e/1FAIpQLSxxxxxxxx/formResponse
```

## 3. `assets/config.js` 채워넣기

`assets/config.js` 파일을 열어 아래 부분을 2번에서 확인한 값으로 바꿔주세요.

```js
formActionUrl: "https://docs.google.com/forms/d/e/본인_폼_ID/formResponse",

entry: {
  classNo: "entry.본인값1",
  studentNo: "entry.본인값2",
  name: "entry.본인값3",
  concept: "entry.본인값4",
  intro: "entry.본인값5",
  motivationCommon: "entry.본인값6",
  careerPlan: "entry.본인값7",
  whySpecialized: "entry.본인값8",
  interestTopic: "entry.본인값9",
  universityResearch: "entry.본인값10",
  qna: "entry.본인값11",
},
```

이 파일 **하나만** 고치면 24명 학생 페이지 전체에 동시에 적용됩니다.

## 4. 응답을 구글 시트로 모으기

구글 폼 상단 **"응답" 탭 → 초록색 스프레드시트 아이콘("스프레드시트 만들기")** 을
눌러 응답이 쌓일 구글 시트를 연결하세요. 학생이 제출할 때마다 이 시트에 한 줄씩
자동으로 추가됩니다.

## 5. 관리자 페이지(`admin/index.html`)에서 한눈에 보기 — ⚠️ 주의

`admin/index.html`은 4번에서 만든 구글 시트를 사이트 안에 통째로 불러와 보여주는
페이지입니다 (좌우 꽉 채움 + 축소/확대 슬라이더 포함). 연결하려면:

1. 4번 구글 시트에서 **공유 → 링크가 있는 모든 사용자: 뷰어(또는 편집자)** 로 설정
2. 시트 주소창의 `.../edit` 링크를 복사
3. `assets/config.js` 의 `adminSheetEmbedUrl` 에 붙여넣기

> **개인정보 주의**: `admin` 페이지는 0번에서 설정한 **관리자 전용 비밀번호**로 따로
> 잠겨 있지만(학생용 비밀번호로는 못 들어옴), 이 역시 진짜 서버 보안은 아닙니다.
> `admin` 페이지 주소와 관리자 비밀번호는 절대 학생에게 알려주지 마세요. 더 확실하게
> 하고 싶다면 이 사이트에 `admin` 폴더 자체를 올리지 않고, 구글 시트 링크를 선생님
> 개인 북마크로만 사용하는 방법도 있습니다.

## 6. GitHub Pages로 배포하기

1. GitHub에서 새 저장소 생성 (예: `3-3-interview-prep`)
2. 이 폴더(`site/`) 안의 모든 파일을 저장소에 업로드 (`.nojekyll` 파일 포함, 숨김 파일이라
   드래그 앤 드롭 시 누락될 수 있으니 GitHub 웹 업로드 또는 `git add -A`로 확인)
3. 저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장
4. 잠시 후 `https://<계정명>.github.io/<저장소명>/` 주소로 접속 가능

## 7. 학생에게 안내하기

학생에게는 사이트 첫 화면(`index.html`) 주소와 0번에서 정한 **입장 비밀번호**를
함께 알려주면 됩니다. 본인 번호·이름
카드를 클릭해 들어가서 작성 후 "제출하기"를 누르면 끝입니다. 다시 들어가 이어서
써도 되고(이전 내용은 다시 불러와지지 않으니 필요하면 제출 전 내용을 따로
저장해두라고 안내해주세요), 제출은 여러 번 해도 매번 새 줄로 쌓입니다.

## 8. 학생을 새로 추가하려면

`tools/generate.py` 파일 안의 학생 목록에 `("25", "이름")` 형식으로 추가하고
`python3 generate.py` 를 실행하면 `students/25/` 폴더가 새로 생깁니다(⚠️ 폴더
이름은 번호만 사용 — GitHub 웹 업로드가 한글 폴더명을 거부하기 때문입니다).
`assets/config.js` 의 `students` 배열에도 같은 학생을 추가해야 메인 목록에
카드가 나타납니다.
